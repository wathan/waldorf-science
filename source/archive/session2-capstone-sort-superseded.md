## Capstone artifact (E) — drafted with C, for Session 2

Carried from the handoff draft, fits Candidate 1 directly: **students sort the block's phenomena into *directly observed / inferred / unknowable*** and justify each placement. The artifact *is* the deep question's answer-in-practice — it makes "where seeing ends and inferring begins" a thing the student must draw a line through and defend. Doubles as authentic evidence for the S2 (interpret data) and S1 (knower-stance) emphases.

**The sort is boundary-construction, not bin-application.** A bare sort against a given taxonomy is normative categorisation (apply the rule, write the implied reason) — analytical mode, grade-11 pitch, exactly the developmental-pitch risk for Candidate 1. The artifact escapes this only when the *boundaries* are the student's to locate and defend, not a rubric handed to them. Three levers make the task synthetic rather than categorical:

- **Contested phenomena by design.** The graded items straddle a boundary. A spectral line is *observed* (the dark band) and *inferred* (the element); redshift is a *chain* — observed wavelength shift → inferred recession → inferred expansion — each link a different bin. The assessment is the straddlers, not the clean cases.
- **"Unknowable" forces a modal cut (three kinds fixed at meso).** The bin is not one category but a *modal* one: the student must label *which kind* of not-knowing, and "too hard" is not one of the kinds — so it can't be a dumping ground, and *in-principle* can't quietly collapse into *not-yet-measured*. The three kinds, fixed at meso (exact wording/boundaries → micro):
  - **In-principle** — no possible observation reaches it (beyond the cosmic horizon; before last-scattering / the CMB).
  - **Instrument-contingent** — unknowable with *these* instruments, not in principle (a faint exoplanet spectrum today).
  - **Not-yet** — open empirical question expected to yield (dark-matter composition).

  The cut is the artifact's most directly grade-12 move (modal reasoning about knowledge itself → **S1** knower-stance), and it links back up the arc: *not-yet* and *instrument-contingent* are exactly where Phase 3's **S3** expert-mediation / consensus does its work.

- **The observed|inferred boundary carries a parallel cut — "what counts as seeing" (also fixed at meso).** B's literal hinge is *where seeing ends and inferring begins* — the **observed|inferred** boundary — so it is graded with the same weight as the modal "unknowable" cut, not left implicit. The student must defend **where direct perception ends**: naked-eye vs instrument-aided vs theory-laden reading (is a dark spectral band "seen"? a CCD image? only the naked eye?). This cashes the **Phase-1 → Phase-2 pivot** (seeing-the-thing → reading-light-about-a-thing-unseen) as the student's own line, and keeps the sort from being lopsided toward the cosmology/unknowable end.
- **Contest the line on de-identified positions.** Position-taking within a community (cf. [ADR-0002](../../adr/0002-action-ethics-subabilities-in-community-position-taking.md)), not rule-matching. The criteria for the bins are the student's *output*, not the task's input.

Net: the categories are the *product* of the student's epistemology, not a given they consume.

### Structure of production — solo artifact, de-personalised contest

The deliverable splits in two, mapped to the competency emphases:

- **Durable individual artifact** — each student's written sort of the shared straddler set **+ the criteria they used to place the line**. Attributable, evidences **S1** (knower-stance) and **S2** (interpret data).
- **De-personalised class contest** — Phase 4 (co-lead) surfaces the disagreement on the straddlers and works it, evidencing **S3** (position-taking). Two mechanisms, used together:
  - **Anonymised placement gallery** — sorts posted de-identified; the class works the *aggregate* disagreement ("three put redshift in *inferred*, two in *unknowable* — what criterion splits them?"). The clash is real; no student stands as the vulnerable owner of a contested claim.
  - **Assigned positions** — a student argues a line *assigned* to them, not necessarily their own. Converts "my view is wrong" (personal exposure) into "I am arguing the *inferred* case" (role) — and forces defending a boundary one might not hold, which is *more* epistemic, not less.

**Why de-personalised (load-bearing class constraint).** This specific class's biography makes showing personal vulnerability to the room unsafe; a live personal defense ("defend *your* line to peers") would suppress the very position-taking it aims to elicit. The contest is therefore run on **anonymised and assigned** positions so the community-contest is genuine while no student is personally on trial. "Community" in the ADR-0002 sense is carried by the de-identified corpus, not by live personal performance.

**Alternatives considered and rejected (for this class):**

| Venue | Why rejected here |
|---|---|
| Solo written sort only (no contest) | Lever 3 (position-taking) has no home → drifts back to solo categorisation; loses the grade-12 synthetic move. |
| Live personal defense to the room (each defends *their own* line) | Direct personal exposure — unsafe given the class biography; would suppress participation. |
| Group-negotiated single sort per table | Personal exposure within the group **and** muddies individual S1/S2 evidence (who knew what?). |
| Written challenge-and-response (named peer ↔ author) | Lower live exposure but still personal attribution of a contested position; slower, heavier to run in the final days. Held as a fallback, not primary. |

**The straddler set is hybrid.** A small **mandatory core** of contested phenomena, teacher-curated against the phase content (e.g. spectral line, the redshift inference-chain, CMB, what lies beyond the cosmic horizon) — this *guarantees* the disagreement lands on epistemically rich cases rather than hoping it does — **plus student-nominated phenomena** ("what *you* found hard to place"), which add ownership and are themselves diagnostic. The core is **meso** (curated against phase structure C); exact items are **micro**. This is the seam where C feeds E: the straddlers must be phenomena the earlier phases actually built — a Session-3 coherence-check concern.
